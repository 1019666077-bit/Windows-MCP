# App Bridge (Moying)

This repository is a MIT fork of [CursorTouch/Windows-MCP](https://github.com/CursorTouch/Windows-MCP) used as the MCP engine for the thin Cursor plugin:

https://github.com/1019666077-bit/app-bridge-plugin

**Free tier** (plugin `mcp.json` `--tools`): `Screenshot`, `Snapshot`, `DisplayInventory` (+ upstream always keeps `ControlStatus`).

Click / Type / other input tools are **not** part of App Bridge Free — treat them as Pro placeholders in the plugin layer.

WeChat may appear in window lists; App Bridge does **not** guarantee WeChat automation.
